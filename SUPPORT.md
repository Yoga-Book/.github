# Getting support

Yoga Book Linux is a community project maintained by volunteers. There is no
commercial support offering, but we try to keep good documentation and respond
to well-formed reports.

## Before asking

1. Read the README and any status or requirements documentation of the
   repository that owns the component you are using.
2. Check that your device model is supported; the **Lenovo Yoga Book YB1-X91L**
   is the primary integration and acceptance target.
3. Search existing issues in that repository for similar reports.

## Where to ask

- **Component-specific problem** — open an issue in the repository that owns
  the component (see the project map in the
  [organization profile](https://github.com/Yoga-Book)).
- **System-wide behavior, installation problems, or help collecting evidence** —
  open an issue in
  [Yoga-Book-Validator](https://github.com/Yoga-Book/Yoga-Book-Validator).
- **Security problems** — do not open a public issue; follow
  [SECURITY.md](SECURITY.md).

## What to include

Good reports get faster and better answers. Include:

- the exact Yoga Book model and firmware version;
- the distribution and running kernel version;
- reproduction steps and expected versus observed behavior;
- relevant logs or a Yoga Book Validator report; and
- whether the result came from automation, a virtual machine, or the physical
  tablet.

Do not publish credentials, serial numbers, private firmware, or other
sensitive data.

## Out of scope

General Linux support, help with other hardware, and distribution-level bugs
are better directed at your distribution's own support channels.
